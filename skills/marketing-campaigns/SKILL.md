# 营销与活动（Marketing and campaigns）

下文中「受众」指本次运营所能触达的人：客户、客人、订阅者，或曾到场者。

复盘只读取活动数据；草稿、文案修改与预算调整都是**暂存**。排期、发送与花费，在审批后由宿主的活动系统执行；移交变更时要说明这一点。

## 每个事实从哪里来

- 花费、收入、回报与状态取自**本轮对话中**查得的 `get_campaign_performance`，并对照运营者陈述的目标来读。目标尚未说明时，先问清这次活动是为了什么，再判好坏。
- 归因收入按渠道自称的「由它带来」来报告，就用这个措辞；凡该注意事项会改变结论的地方，都要一并说明（一次续费触达被记为带来续费，而这些续费本来每年都会发生）。
- 窗口过短或花费过薄时，报告为「尚不足以判断」，并给出值得再看的那一天——由活动日期与所给本地时间推算。
- 草稿沿用记忆中保存的品牌口吻；未保存且口吻重要时，问一次，此后一直沿用该答案。
- 文案中的产品事实取自商品记录（`get_listing`）或运营者本人；两者都没有提供的规格、省下金额或「最……」类说法，一律不写。

## 活动形态

- 每份草稿只给**一个**受众意图和**一个**要推动的可度量指标，并作为受众与目标传给 `stage_campaign`。
- 各形态的差别只在这两个字段上。拉新推广指名「此前从未购买的人」，指标是窗口内的首单；唤醒指名「停用满一定周期的人」，指标是一个月后他们的活跃；到店前或最后召集触达指名「有临近日期的人」，指标是它应推动的加购或售罄率。
- 受众与投放位都按**意图**书写（「未来七天内到店」）。定向设置存在于宿主系统中；不要把它们描述成已设定。

## 按形态复盘活动

- 分形态读回报：拉新看归因收入对花费；留存类触达看受众随后的行为对该受众的常规水平。数字中找不到这样的基准时，就说本次触达的效果无法与「受众本来就会发生的行为」区分开。
- 两类回报**并排**报告，并说明每个活动依据哪个指标评判；不要用单一数字给它们排序。
- 只复盘 `get_campaign_performance` 返回的活动；它未包含的触达，报告为「本流程不可见」。

## 预算

- 除非运营者另有说明，总额视为固定；因此建议给某个活动加码时，必须同时指名**哪个活动减少**。
- 重新分配须建立在**已测得的回报差异**上，并以预期口吻表述。窗口过短或花费过薄时，建议等待，并给出再看一次的日期。

## 暂存与预览

- 用 `stage_campaign` 暂存草稿、文案修改或预算调整；改动既有活动须使用 `get_campaign_performance` 返回的 id。只暂存被要求的那一项：文案刷新不带预算变动，预算调整不带新文案；运营者要的草稿即使与在跑活动的受众重叠也要暂存，并在预览旁注明重叠。
- 此处会遇到的护栏是本部署的活动预算上限；可提供的替代方案是「在同一上限下发出同一封」。
- 应用之后，说明该次发送现在处于宿主活动系统的哪个位置；发送日期与花费由该系统承担。
- 复盘以 `present_metrics` 收尾，前面带一两句说明；草稿或预算调整则以其预览收尾。

## 执行流程

1. **定目标**。先确认运营者陈述的目标。判据：目标已明确；未明确则先问「这次活动是为了什么」，不得跳过。
2. **取数**。在同一轮对话中调用 `get_campaign_performance`，取花费、收入、回报与状态。判据：数据来自本轮返回；用旧数据须显式标注。
3. **判可否读**。按活动日期与本地时间判断窗口是否足够，并检查花费是否过薄。判据：不足时报「尚不足以判断」并给出可再看的日期。
4. **写草稿**。确定**一个**受众意图与**一个**可度量指标，作为受众与目标传给 `stage_campaign`；文案中的产品事实逐条回溯到 `get_listing` 或运营者。
5. **暂存**。用 `stage_campaign` 暂存；改动既有活动须用返回的 id。判据：只暂存被要求的那一项，不多带。
6. **移交说明**。告知排期、发送与花费由宿主活动系统在审批后执行，并说明该次发送当前所处位置。
7. **呈现**。复盘用 `present_metrics` 收尾（前带一两句）；草稿或预算调整用其预览收尾。

## 边界与降级

- **未陈述目标**：先问，再判好坏；不得凭默认目标下结论。
- **窗口过短或花费过薄**：报告「尚不足以判断」并给出再看日期，不出结论。
- **缺少基准**：留存类触达无该受众常规水平时，明说效果无法与自然发生的行为分离。
- **归因局限**：凡注意事项会改变结论，必须在结论旁声明；不得只报归因收入。
- **文案中的产品事实无来源**：规格、省下金额、「最……」类说法一律删除，不猜测、不替运营者补。
- **撞上预算上限护栏**：提供「在同一上限下发出同一封」作为替代，不绕过上限。
- **活动不在工具返回中**：报告为「本流程不可见」，不凭记忆或推测复盘。
- **无网络或工具不可用**：改为人工按本流程的判定规则整理已有数据，并在产出开头标注数据来源与缺失项。

## 质量自检

- [ ] 每份草稿只含一个受众意图与一个可度量指标。
- [ ] 受众与投放位均以意图表述，未被描述为已设定。
- [ ] 归因收入的注意事项已在结论旁声明。
- [ ] 两类回报并排呈现，未用单一数字排序。
- [ ] 预算重新分配同时指名了减少的一方，且以预期口吻表述。
- [ ] 文案中每个产品事实均可回溯到 `get_listing` 或运营者。
- [ ] 只暂存了被要求的一项（文案／预算／草稿未互相夹带）。
- [ ] 引用的资源路径全部存在，无占位符残留。
