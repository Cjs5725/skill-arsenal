# {技能中文名} · 安装与上传说明

## 一、本地版（可直接用）

适用：保留原始脚本、嵌套结构与联网能力，装在本机 WorkBuddy。

1. 复制目录到用户级技能目录：

   ```
   ~/.workbuddy/skills/{slug}/
   ```

2. 确认目录结构：`SKILL.md` 在根目录，脚本与资源保持原路径。
3. 重启会话或重新加载技能列表后生效。
4. 若技能依赖第三方包，先在本机环境安装对应依赖。

## 二、平台版（可上传）

适用：上传 open.workbuddy.cn，供他人安装。

1. 取 `dist/{slug}.zip`，确认解压后根目录即可见 `SKILL.md`（root 直铺）。
2. 确认包内仅含 `references/` `scripts/` `assets/` 三个一级目录，无嵌套子目录。
3. 打开 WorkBuddy 开放平台 → 技能上传 → 选择 zip。
4. 上传后用平台自检确认七项字段齐全：name、description、version、display_name、display_name_en、description_zh、description_en。

## 三、上传前必查

- [ ] 目录名与 `name` 完全一致
- [ ] zip 根目录直接是 SKILL.md，未多套一层目录
- [ ] 无联网强依赖、无第三方 import
- [ ] 无密钥、令牌、内部地址
- [ ] 无 TODO 与占位符残留
- [ ] 许可证允许公开发布（source-available 内容请勿上传）

## 四、常见问题

| 现象 | 原因 | 修复 |
|---|---|---|
| 报「压缩包缺少 SKILL.md 文件」 | zip 内多套了一层目录 | 以技能目录为根重新压缩 |
| 报「目录层级超限」 | 资源目录内还有子目录 | 拉平为两级，文件名用双下划线连接 |
| 报 frontmatter 解析错误 | 值内含未引号的「冒号+空格」或中文引号 | 加英文引号或改写措辞 |
| 技能列表不显示 | 目录名与 name 不一致 | 统一命名 |
| 沙箱评测不通过 | 技能依赖联网或外部依赖 | 改为内置知识优先，保留离线路径 |
