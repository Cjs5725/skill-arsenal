# 可迁移性体检清单

> 用途：第 2 步体检与第 5 步交付前检查的依据。脚本不可用时，按本清单手工核对。

## 一、五类风险与判定标准

### A. 外部依赖（最高频阻断源）

| 检查项 | 判定 | 处置动作 |
|---|---|---|
| `import` 了标准库以外的包（requests、pandas、PyPDF2、python-docx 等） | 阻断（平台版） | 改为标准库实现；无法替代则把能力改为文字规则，或写入「不适用于」 |
| 脚本内调用 curl / wget / pip install / npm install | 阻断 | 删除安装类命令；联网取数改为「本地文件优先」 |
| 正文要求「先联网查最新资料」且无离线兜底 | 降级 | 改为「内置知识库优先，联网为可选增强」并保留离线路径 |
| 依赖特定 CLI（如 claude、gh、ffmpeg） | 阻断 | 删除或改为可选；必需则标注为本地版专属能力 |

标准库白名单判定：取 import 顶层模块名，不在 `sys.stdlib_module_names` 内即视为第三方。

### B. 目录层级

| 检查项 | 判定 | 处置动作 |
|---|---|---|
| 文件相对路径超过两级（如 `scripts/helpers/x.py`） | 阻断 | 拉平为 `scripts/helpers__x.py` 并重写正文引用 |
| 一级目录名不在 references / scripts / assets 内 | 降级 | 重命名或内容迁移到对应标准目录 |
| 存在 `.claude-plugin`、`spec`、`template` 等仓库级目录 | 通过 | 不属于技能本体，搬运时排除 |

### C. 命名与保留词

| 检查项 | 判定 | 处置动作 |
|---|---|---|
| name 含 claude / anthropic / gpt / chatgpt / gemini / copilot / codex | 阻断 | 删除该 token 后重新 slug 化 |
| name 含大写、下划线、空格或长度 >64 | 阻断 | slug 化并截断 |
| 目录名与 name 不一致 | 阻断 | 统一为 name |
| description 超过 1024 字符 | 阻断 | 压缩为「何时用 + 产出 + 不适用」三段式 |

### D. 许可证与合规

| 检查项 | 判定 | 处置动作 |
|---|---|---|
| 无 LICENSE 文件 | 降级 | 报告标注「许可未声明」，仅本地自用 |
| 路径含 docx / pdf / pptx / xlsx 且来自 anthropics 仓库 | 阻断（公开分发） | 标注 source-available，仅产本地版，公开上传需自行取得授权 |
| 包内含密钥、令牌、内部地址 | 阻断 | 清除，改为环境变量占位说明 |
| 许可证为 Apache-2.0 / MIT | 通过 | 可搬运，建议保留署名 |

### E. 工具名与运行时

| 检查项 | 判定 | 处置动作 |
|---|---|---|
| allowed-tools 含平台工具集外工具 | 阻断 | 删除并改为正文步骤或写入边界 |
| 正文引用平台外工具 | 阻断 | 同上 |
| 依赖沙箱不提供的执行环境（Docker、GPU） | 阻断 | 写入「不适用于」 |

## 二、结论判定规则

- 存在任一阻断项且无法处置 → 结论「不建议搬」，说明具体阻断原因。
- 存在阻断项但均已按处置动作完成改造 → 结论「需改造（已完成）」。
- 无阻断项、仅有降级项 → 结论「需改造」。
- 五类全为通过 → 结论「可直接搬」。

## 三、交付前检查表

**结构**
- [ ] SKILL.md 位于包根目录
- [ ] 目录名与 `name` 完全一致
- [ ] 仅含 references / scripts / assets，无嵌套子目录
- [ ] zip 为 root 直铺，解压后根目录即可见 SKILL.md

**字段**
- [ ] 七项必填齐全：name、description、version、display_name、display_name_en、description_zh、description_en
- [ ] 无未引号的「冒号+空格」
- [ ] 无中文引号、无尖括号
- [ ] description 说明「何时使用」且写明「不适用于」

**内容**
- [ ] 正文使用祈使句，无第二人称
- [ ] 正文体量 ≤5000 词，超长部分已下沉 references
- [ ] 引用的资源路径全部真实存在
- [ ] 无 TODO、待填写、{PLACEHOLDER} 残留
- [ ] 无硬编码本机绝对路径
- [ ] 无真实密钥或令牌

**双轨**
- [ ] 平台版零联网强依赖、零第三方 import
- [ ] 本地版保留原脚本与原结构
- [ ] 改动清单逐条记录字段改动与文件搬迁
- [ ] 迁移报告含体检结论、改动摘要、残留风险、安装与上传步骤

## 四、常见缺陷与修复

| 缺陷 | 修复 |
|---|---|
| 只改 frontmatter 就上传，目录仍嵌套 | 先拉平再压缩 |
| zip 内多套一层目录 | 压缩时以技能目录为根，直接铺文件 |
| 保留原 description 未压缩导致超长 | 改写为三段式并控制在 1024 字符内 |
| 只产平台版，本地脚本依赖丢失 | 双轨产出，本地版保留原结构 |
| 许可证风险未提示 | 报告中单列合规提示栏 |
